DECISOES TECNICAS PRINCIPAIS
----------------------------------------------------------------
- Persona: beneficiario final em autoavaliacao clinica.
- Modelo: Llama 3.3 70B Versatile via Groq API (LPU).
  Comparativo com OpenAI GPT-4.1 documentado no README.
- Justificativa: latencia ultrabaixa (~300ms TTFT, 10x mais
  rapido que GPU tradicional), custo zero no tier gratuito,
  open weights (viabiliza on-premise para LGPD), function
  calling estruturado nativo.
- Framework: SDK nativo Groq na Sprint 1.
  LangGraph previsto para Sprint 3 (multi-agente).
- Vector store (Sprint 2): ChromaDB +
  sentence-transformers (open-source).
- Princípio HITL obrigatorio:
  agente nao diagnostica nem prescreve.
- Conformidade LGPD: pseudonimizacao (BNF-XXXXX),
  sem PII em logs, segredos via .env / Colab Secrets.

COMO EXECUTAR A POC
----------------------------------------------------------------
Opcao A - Google Colab (recomendado):
  1. Obter chave Groq gratuita: https://console.groq.com/keys
  2. Upload do notebook /notebooks/sprint1_poc.ipynb
  3. Em "Secrets", criar GROQ_API_KEY com sua chave
  4. Executar todas as celulas

Opcao B - Local:
  git clone https://github.com/lincoln743/bluadiagnostics.git
  cd bluadiagnostics
  python -m venv .venv && source .venv/bin/activate
  pip install -r requirements.txt
  cp .env.example .env  # cole sua GROQ_API_KEY
  jupyter notebook notebooks/sprint1_poc.ipynb
